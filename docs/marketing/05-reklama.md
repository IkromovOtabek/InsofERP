## 6. Konversiyalarni kuzatish

### 6.1 Maqsadlar

| Hodisa | Qachon | Yandex Metrica maqsadi | GA4 hodisasi | Asosiy (Ads'ga) |
|---|---|---|---|---|
| Forma yuborildi | Server muvaffaqiyatli javob berganda (ERP `Lead` yaratildi) | `lead_form` (JavaScript-hodisa) | `generate_lead` (`form_name`, `product`) | Ha |
| Telefon bosildi | `tel:` havolaga klik | `phone_click` | `click_phone` | Ha |
| Telegram bosildi | Telegram havolasiga klik | `telegram_click` | `click_telegram` | Ha |

Yandex Direct strategiyasi: `lead_all` maqsadi; forma qiymati telefon bosishdan yuqoriroq (masalan, forma = 1, telefon = 0,5 — nisbat 1-oydan keyin real konversiya bo'yicha).

### 6.2 Sayt kodi (dasturchi uchun)

```js
// Bitta yordamchi funksiya — hamma hodisalar shu orqali
function track(goal, params = {}) {
  try { window.ym?.(YM_ID, "reachGoal", goal, params); } catch {}
  try { window.gtag?.("event", GA_EVENTS[goal] ?? goal, params); } catch {}
  try { window.fbq?.("track", goal === "lead_form" ? "Lead" : "Contact"); } catch {}
}
const GA_EVENTS = {
  lead_form: "generate_lead", phone_click: "click_phone", telegram_click: "click_telegram",
  calc_done: "calculator_complete", phone_copy: "copy_phone",
};
// lead_form — faqat server 200 qaytargandan keyin, tugma bosilganda emas
```

### 6.3 Offline konversiya (2-oydan)

- Forma bilan birga saqlanadi: `utm_*`, `yclid`, `gclid`, `fbclid`, Metrica `ClientID` (`_ym_uid`), GA `client_id`.
